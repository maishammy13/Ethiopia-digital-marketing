# Service Package Matrix

## Purpose

[03_OFFER_TIERS.md](03_OFFER_TIERS.md) defines what Foundation, Guided Growth, and Managed Growth mean in general. This file makes each tier concrete for every major service category, so a salesperson or account lead can say precisely what a client gets at each level for the specific service that client actually needs — without having to improvise or expose the full [../02_SERVICE_CATALOGUE.md](../02_SERVICE_CATALOGUE.md).

**How to use this file:** a client rarely buys every category below at once. Combine the relevant categories for their situation into one proposal using the tier consistently across all of them (see [10_PROPOSAL_STRUCTURE.md](10_PROPOSAL_STRUCTURE.md)) — a client should not be Managed Growth on their website and Foundation on their Google Business Profile without a deliberate, discussed reason, since that mismatch usually signals an unclear conversation about what they actually need.

Every item below maps to the detailed delivery process in the corresponding `services/` file — this matrix is the packaging layer, not a replacement for the operational depth already documented there.

## Website Services

*(Full delivery detail: [../services/01_WEBSITE_STRATEGY.md](../services/01_WEBSITE_STRATEGY.md) through [../services/05_DOMAIN_HOSTING_AND_MAINTENANCE.md](../services/05_DOMAIN_HOSTING_AND_MAINTENANCE.md))*

**Foundation**
- Website plan and page-structure recommendation
- Template recommendation matched to the client's segment
- A copywriting questionnaire the client fills in themselves
- Client builds or populates the website using the template and their own answers

**Guided Growth**
- Agency creates the design and site structure

- Shared implementation — agency builds the technical foundation, client contributes content

**Managed Growth**
- Full strategy (per [../services/01_WEBSITE_STRATEGY.md](../services/01_WEBSITE_STRATEGY.md))
- Design (per [../services/02_WEBSITE_DESIGN.md](../services/02_WEBSITE_DESIGN.md))

## SEO

*(Full delivery detail: [../services/06_TECHNICAL_SEO.md](../services/06_TECHNICAL_SEO.md), [07_ON_PAGE_SEO.md](../services/07_ON_PAGE_SEO.md), [08_OFF_PAGE_SEO_AND_LINK_BUILDING.md](../services/08_OFF_PAGE_SEO_AND_LINK_BUILDING.md), [09_LOCAL_SEO.md](../services/09_LOCAL_SEO.md))*

**Foundation**
- A technical and on-page SEO audit with a prioritized fix list
- Keyword research delivered as a reference document
- A local-citation checklist the client works through themselves

**Guided Growth**
- Agency implements the highest-priority technical fixes
- Agency provides a keyword-to-page map and on-page recommendations; client's own team or web developer implements them
- Agency builds core local citations; client maintains consistency going forward using the provided NAP reference

**Managed Growth**
- Full technical SEO, implemented and monitored on an ongoing basis
- Full on-page optimization, implemented and iterated based on performance
- Off-page/link-building program
- Full local SEO management (citations, location pages, local schema)
- Monthly reporting with honest attribution framing (per [../services/24_ANALYTICS_TRACKING_AND_REPORTING.md](../services/24_ANALYTICS_TRACKING_AND_REPORTING.md))

## How to Use This File

- Combine the relevant categories at a consistent tier into one proposal — see [10_PROPOSAL_STRUCTURE.md](10_PROPOSAL_STRUCTURE.md).
- Price each combined package using [06_PRICING_CALCULATOR.md](06_PRICING_CALCULATOR.md), not by simply adding list prices — bundling multiple categories usually reduces the account-management overhead per category, which should be reflected in the price.
- Cross-check the recommended tier against the client's segment using [05_CUSTOMER_VALUE_BY_SEGMENT.md](05_CUSTOMER_VALUE_BY_SEGMENT.md) before presenting — not every segment should default to the same tier for the same category.
