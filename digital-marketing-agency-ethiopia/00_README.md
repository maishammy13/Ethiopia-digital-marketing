# Digital Marketing Agency Operating System — Ethiopia

This folder is a complete, implementation-ready operating system for launching and running a digital-marketing agency serving businesses in Ethiopia. It combines a service delivery manual, a sales playbook, an Ethiopia customer-segment market map, a client-onboarding system, a quality-control manual, and a scaling plan into one connected set of files.

## How to use this system

- **New employee or freelancer:** start with a specific file in `services/` or `operations/` for the task you've been assigned. Each service file ends with a Standard Operating Procedure (SOP) checklist you can follow directly.
- **Sales or business development:** start with `market-mapping/` to identify who to sell to, then `commercial/` for packages, pricing, and scripts.
- **Founder or manager:** start with `01_AGENCY_STRATEGY_AND_POSITIONING.md`, then `implementation/` for the rollout roadmap and KPI dashboard.
- **Client-facing work:** use `templates/` for the actual documents (briefs, checklists, reports) handed to or filled in with clients.

## Ground rules that apply across every file

1. No invented facts. This system does not fabricate market statistics, prices, company names, contact details, or regulations. Where real information is required and unavailable, the file explains how to research or verify it instead of guessing.
2. Vague instructions are not allowed. Activities like "improve SEO" or "manage social media" are always broken into specific, ordered, checkable actions.
3. One-time setup work is always separated from recurring (daily/weekly/monthly/quarterly) work.
4. Agency responsibilities are always separated from client responsibilities.
5. Every deliverable has a KPI and a quality check attached to it.
6. Nothing here is legal, tax, or regulatory advice. Sections that touch legal or platform-policy matters are flagged for verification against current Ethiopian law and current platform terms.
